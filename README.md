# Zeynep Köymen

Computer Engineering student at Ankara University. I work on machine learning, mostly computer vision. Lately that means medical image classification, object detection and tracking.

### [Melanoma detection](https://github.com/zkoymen/melanoma-detection-ham10000)

This started as our Digital Image Processing course project and grew into a paper at TOK 2026, the 27th National Conference on Automatic Control. We compared ten methods, classical and deep, under one lesion-grouped and leakage-audited protocol. Grad-CAM maps show which parts of a lesion each network relies on.

### Computer vision

- [yolo26-cnn-architecture-lab](https://github.com/zkoymen/yolo26-cnn-architecture-lab) takes YOLO26 apart: feature maps, C3k2 block ablations, pretrained weight transfer and fine-tuning.
- [nanotrack-webcam-lab](https://github.com/zkoymen/nanotrack-webcam-lab) tracks one selected object on a live webcam with NanoTrackV2. A small YOLO26 detector watches for drift and finds the target again when tracking fails.
