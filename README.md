Computer Engineering student at Ankara University. I work on machine learning systems — computer vision engineering (medical imaging, object detection, tracking) on one side, machine learning engineering (classical methods, end-to-end pipelines, LLM systems) on the other.

### 🔬 Melanoma detection on dermoscopy images

![Paper](https://img.shields.io/badge/paper-TOK_2026-8A2BE2?style=flat)

[**melanoma-detection-ham10000**](https://github.com/zkoymen/melanoma-detection-ham10000) started as our Digital Image Processing course project and grew into a paper at **TOK 2026**, the 27th National Conference on Automatic Control. Ten classical and deep methods compared under one lesion-grouped, leakage-audited protocol, with Grad-CAM maps showing which parts of a lesion each network relies on.

### What I work on
